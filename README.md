# Auto Loan Portfolio Analytics & Self-Service Dashboard

> ⚠️ **ALL DATA IS SYNTHETIC.** The 520,000 loan-level records are generated by `src/generate.py`
> (seed 42) for demonstration. They are **NOT** real SEC EDGAR / Reg AB II filings, and no real
> filings were downloaded. Any resemblance to a real portfolio is coincidental.

## Overview
Loan-level portfolio analytics: delinquency, prepayment, and credit-score trends by vintage,
term, and vehicle type — with a PostgreSQL-compatible SQL layer, a Power BI dashboard spec
(DAX + data model + visuals), a 1-page business memo, and a working Streamlit demo of the same KPIs.

## How to run
```bash
pip install -r requirements.txt
python run_all.py            # generate 520,000 rows -> /tmp/auto_loans.db (SQLite) -> outputs/
python -m pytest tests/ -q
streamlit run app.py         # demo dashboard (Power BI Desktop is unavailable locally)
python scripts/refresh.py    # automated-refresh pattern (daily re-run)
```

## Measured results (actual run, synthetic data, seed 42)
- Loans: **520,000**; total originated balance: **$12,920,845,815**
- Overall 60-day delinquency: **5.55%**; 30-day: **6.72%**; prepayment rate: **13.39%**
- Average credit score: **675.2**; average interest rate: **6.63%**
- **Headline:** 72+ month loans with credit score < 640: **10.38%** 60-day delinquency
  (n = 57,156) vs all other loans: **4.95%** (n = 462,844) → ratio **2.10x**
- By credit band (60-day): <580 **11.80%**, 580–639 **8.86%**, 640–679 **5.76%**, 680–719 **3.95%**, 720+ **2.67%**
- By term (60-day): 36mo **4.92%**, 48mo **4.93%**, 60mo **4.79%**, 72mo **6.60%**, 84mo **6.53%**
- By vehicle (60-day): New **5.14%**, Used **5.88%**
- By vintage (60-day): 2020 **5.44%**, 2021 **5.35%**, 2022 **5.43%**, 2023 **5.58%**, 2024 **5.74%**, 2025 **5.69%**
- Prepayment by term: 36mo **16.23%**, 48mo **16.16%**, 60mo **12.48%**, 72mo **12.21%**, 84mo **12.11%**

## 1-page memo
See `docs/memo.md` — three actionable insights: (1) tighten/price 72+ month sub-640 lending and
early-watch existing loans; (2) price and reserve by score band, not a single cutoff;
(3) monitor used-vehicle and long-term segments monthly, but concentrate intervention where risk concentrates.

## Layout
- `run_all.py` — reproducible end-to-end run (generate → SQLite → SQL analysis → `outputs/`)
- `src/` — `generate.py`, `analyze.py`
- `sql/` — `schema.sql` (PostgreSQL-compatible), `analysis.sql`
- `docs/` — `memo.md`, `powerbi/` (DAX measures, data model, visual specs)
- `scripts/refresh.py` — automated refresh pattern; `app.py` — Streamlit demo
- `outputs/` — `kpis.json`, per-dimension CSVs, `sample_1000.csv` (the full 520K-row dataset and
  SQLite file are regenerated at runtime and are NOT committed, to keep the repo lean)
- `tests/` — pytest suite

## Caveats
- Synthetic data only; risk relationships are built-in generator assumptions (documented in
  `src/generate.py`), not estimated from real loans. Do not use these rates for real lending decisions.
- SQLite locally; DDL is kept PostgreSQL-compatible for the production warehouse.
- Streamlit demo instead of a native .pbix (Power BI Desktop unavailable locally).
